## Status

**Stable**

## Current support

- JSON and ordered binary serialization, including nested models and arrays.
- ES modules by default; `#[$js:JavaScriptModuleFormat("commonjs")]` emits CommonJS.

## Notes

Enable binary methods with `#[SerializationType("binary")]`. `serializeBinary()`
returns a `Uint8Array`; `Model.deserializeBinary(bytes)` returns the decoded model
or `null` for invalid input in the default strict mode. Both byte orders are supported.
Binary `int64`, `uint64`, and nanosecond `datetime` values decode as `bigint` to
preserve precision. The runtime needs `DataView`, `TextEncoder`, and `TextDecoder`;
Node's `Buffer` and external runtime packages are not required.
